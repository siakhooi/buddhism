# buddhism
printable buddhism sutras with Hanyu Pinyin.

| Directory | CBETA | 佛经             |
| --------- | ----- | ---------------- |
| xin-jing  | T0251 | 般若波羅蜜多心經 |

## Steps to Update
- update `config.yaml`, `dict.yaml`, `sutra.txt` accordingly
- run `make build`
- check changes in files `content.tex`, `meta.tex`
- `git add` files
- `git commit`
- `git push`
